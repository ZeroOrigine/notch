## Security fixes made before adoption
1. All clients use notch-api (no Nova-origin spoofing, no open proxy, no client-side model key unless the user saves their own on the Mac).
2. Mac mouse/keyboard: Touch ID once per task in code (not left to the model); Touch ID again for sending keys in messaging apps and browsers (`Safety.isSendingKey`).
3. Mac public download removed until Developer ID + notarization.
4. `open_file` refuses programs, scripts, installers (`Safety.isOpenableDocument`).
5. Open-at-login is now opt-in (default off).
6. Chrome voice runs in an extension window (`voice.html`); websites never get the microphone. Found and fixed during testing: error text was sent as speech and looped in chat mode.
7. Web: strict CSP (no inline script, no third-party script), nosniff, DENY framing, HSTS, Permissions-Policy.
8. iPhone and every client: http/https links only.
